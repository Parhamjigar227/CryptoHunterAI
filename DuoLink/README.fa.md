# DuoLink — نسخه پایه 0.1.0

این فایل یک پایه قابل توسعه اندروید است، نه پیام‌رسان آماده.

## پیاده‌سازی‌شده
- پروژه Kotlin + Jetpack Compose
- صفحه خانه، مخاطب اختصاصی «نسرین خانم»، صفحه درباره برنامه و تنظیمات
- متن دقیق درباره برنامه: «نسرین خانم — این برنامه مخصوص شما ساخته شده است.»
- تصویر ارسالی به‌عنوان عکس مخاطب و لوگوی اولیه
- پیش‌نمایش چت با پیام‌های محلی نمونه

## هنوز پیاده‌سازی نشده
ارسال اینترنتی، رمزنگاری سرتاسری، جفت‌سازی QR، WebRTC، تماس صوتی/تصویری، انتقال فایل، STUN/TURN، Signaling و تست امنیتی مستقل.

**پیام‌های نمونه فقط در همان گوشی هستند.** دکمه تماس و پیوست نیز فعلاً عملیاتی نیستند. این موارد عمداً شفاف‌اند تا پوسته اولیه با پیام‌رسان امن اشتباه نشود.

## باز کردن پروژه
1. Android Studio را نصب کنید.
2. از صفحه آغازین Open را بزنید و پوشه DuoLink را انتخاب کنید.
3. اجازه دهید Gradle Sync کامل شود.
4. گوشی اندرویدی یا شبیه‌ساز را انتخاب و Run کنید. برای ساخت از خط فرمان ویندوز می‌توانید `gradlew.bat assembleDebug` را اجرا کنید؛ اسکریپت در اجرای اول Gradle 8.9 را از منبع رسمی دریافت می‌کند.

پیش‌نیاز پیشنهادی: Android Studio جدید، JDK 17، Android SDK 35.

## مرحله بعد
ابتدا threat model و انتخاب کتابخانه رمزنگاری معتبر و نگهداری‌شده؛ سپس جفت‌سازی QR و تست تغییر هویت. رمزنگاری اختصاصی نسازید. برای تماس و انتقال زنده WebRTC مناسب است. Signaling فقط باید اطلاعات لازم برای راه‌اندازی اتصال را ردوبدل کند. TURN ممکن است برای برخی شبکه‌ها لازم باشد و محتوای عبوری باید همچنان رمزنگاری‌شده بماند.

هرگز کلید خصوصی را در کد یا سرور قرار ندهید. از Android Keystore برای کلیدهای محلی پشتیبانی‌شده استفاده کنید. پیش از استفاده واقعی، ممیزی امنیتی مستقل لازم است.
