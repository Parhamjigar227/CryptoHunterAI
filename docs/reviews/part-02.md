# بازبینی قسمت ۲ — موتور تحقیق و جمع‌آوری اطلاعات

## فایل‌ها
| فایل | هدف | ورودی → خروجی |
|---|---|---|
| `src/safe-fetch.js` | fetch امن: فقط https عمومی، timeout، سقف حجم، فهرست مجاز content-type، ریدایرکت دستی با اعتبارسنجی هر گام | URL → `{ok,text,finalUrl,...}` یا `{ok:false,error:{code,message}}` (هرگز throw نمی‌کند) |
| `src/sources/website.js` | سایت رسمی: عنوان، توضیح، متن، لینک‌های GitHub/X/Telegram/Discord/docs، جست‌وجوی عبارت‌های پرخطر | URL → رکورد منبع |
| `src/sources/github.js` | اطلاعات عمومی مخزن از API رسمی GitHub (ستاره، تاریخ ساخت و آخرین push، آرشیو، فورک، لایسنس) | `{owner,repo}` → رکورد منبع |
| `src/sources/coingecko.js` | تطبیق توکن با نام یا آدرس قرارداد؛ عرضه، رتبه، قراردادها، مخزن GitHub | `{name,chain,contract}` → رکورد منبع |
| `src/research.js` | اجرای موازی منابع، پیدا کردن مخزن GitHub از سایت یا CoinGecko، رویداد پیشرفت | ورودی اعتبارسنجی‌شده → `{sources,notes,limited,usable}` |
| `tests/*.test.js`, `tests/helpers.js`, `tests/fixtures/github-repo-real.json` | آزمون‌ها؛ فیکسچر GitHub پاسخ واقعی API همین مخزن است | |

هر رکورد منبع: `id, title, url, fetchedAt, ok, data, error, limitations`.

## آزمون‌های اجراشده (واقعاً اجرا شد)
- `npm test`: **۳۹ آزمون، ۳۹ پاس**.
- **آزمون زنده روی شبکهٔ واقعی:** `fetchGithubRepo` روی `Parhamjigar227/CryptoHunterAI` داده واقعی برگرداند (`ok:true`، تاریخ‌ها و شمارنده‌ها صحیح).
- SSRF: آدرس‌های localhost، IP (دهدهی/هگز)، metadata (169.254.169.254)، IPv6، userinfo، پورت غیراستاندارد، http، و ریدایرکت به همهٔ این‌ها رد می‌شوند (آزمون واحد).
- محتوای `<script>` سایت‌ها به خروجی نمی‌رسد (آزمون با رشتهٔ تزریقی).

## آنچه آزمایش **نشده**
- **CoinGecko روی API واقعی:** از محیط توسعه قابل دسترس نیست (`000`). فیکسچرها از روی مستندات نوشته شده‌اند، نه ضبط‌شده. مسیرهای `/search` و `/coins/{platform}/contract/{addr}` و شناسه‌های پلتفرم از دانش من هستند و در مستندات دریافت‌شده تأیید نشدند. **تا اولین اجرای واقعی «پیاده‌سازی شده ولی آزمایش نشده» است.**
- **دریافت سایت رسمی روی اینترنت واقعی:** فقط با fetch شبیه‌سازی‌شده آزمایش شده.
- رفتار `redirect: "manual"` در runtime واقعی Workers (در Node آزمون شد).

## محدودیت‌ها و ریسک‌های شناخته‌شده
1. GitHub بدون توکن ۶۰ درخواست در ساعت به ازای هر IP می‌دهد و IPهای Workers مشترک‌اند؛ برای پایداری، Secret اختیاری `GITHUB_TOKEN` پشتیبانی می‌شود.
2. CoinGecko بدون کلید نرخ پایینی دارد؛ در صورت ۴۲۹ به‌صراحت گزارش می‌شود.
3. سایت‌های جاوااسکریپتی (SPA) متن کمی برمی‌گردانند؛ در `limitations` ثبت می‌شود.
4. اسکن عبارت‌های پرخطر فقط «ذکر» را پیدا می‌کند و سیگنال قطعی نیست (هشدارهای قانونی «seed phrase را نده» هم تطبیق می‌خورند)؛ تحلیل باید با زمینهٔ متن قضاوت کند.
5. جست‌وجوی وب عمومی (موتور جست‌وجو) پیاده‌سازی نشده: بدون کلید API رایگان قابل اعتماد نیست؛ تحقیق محدود به منابع بالاست و گزارش باید این را اعلام کند.
6. کاوشگر بلاکچین (Etherscan و …) هنوز متصل نیست؛ تأیید قرارداد فقط از طریق CoinGecko.
